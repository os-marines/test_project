## Marginalia

Claudeで動くリサーチノートブックです（NotebookLMのような使い方ができます）。

- **ソース**: PDF、テキスト、Markdown、CSV、HTML、画像（スクリーンショットやスキャンPDFはClaudeが読み取ります）、貼り付けたテキスト、トピックからAIが書く入門資料
- **チャット**: ソースだけを根拠に回答し、文ごとに出典パッセージ（`1·2` のような黄色いマーク）を付けます。マークをクリックすると原文のその箇所が開きます。
  - モード: 根拠のみ / 知識も使う（一般知識には印が付きます）/ 先生（ソクラテス式）/ 批評家
- **スタジオ**
  - 音声解説: 2人のホストによる番組。再生中に質問すると、ホストが番組内で答えて元の話に戻ります。
  - ブリーフィング、学習ガイド、FAQ、タイムライン、マインドマップ、フラッシュカード、クイズ、スライド、データ表（CSV）、自由な指示
  - 論点チェック: ソース間で一致する点・食い違う点・どのソースも答えていない問い・各ソースの信頼性
- **メモ**: 保存した回答や出力は、もう一度ソースとして追加できます。

### ファイル

| ファイル | 内容 |
|---|---|
| `marginalia/app.html` | claude.ai Artifact 版のソース（Claudeの呼び出し、音声、保存はArtifactの機能を使います） |
| `marginalia/index.html` | 単体で開ける版（`marginalia/build.sh` で生成）。設定画面で Anthropic API キーを入れると動きます |

単体版ではAPIキーはブラウザの localStorage にだけ保存され、`api.anthropic.com` へ直接送られます。自分専用で使ってください。
